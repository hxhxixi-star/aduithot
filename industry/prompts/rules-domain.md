
【验厂审核领域翻译规则 — 本平台 100% 是验厂审核与供应链合规行业内容，严格遵守】

1. 歧义默认值：以下词在中文有非验厂歧义，**一律按验厂合规含义翻译**：
   - Audit = 审核（验厂语境，不译"审计"）
   - Auditor = 审核员（不译"审计师"）
   - Assessment = 评估（SLCP 语境用"评估"，不用"审核"）
   - Verification = 验证（SLCP 验证员/验证流程）
   - Finding = 不符合项（审核发现；不译"发现"单独使用）
   - NC / Non-conformance = 不符合项
   - CAP / CAPA = 整改计划 / 整改措施（Corrective Action Plan）
   - Compliance = 合规（不译"服从"）
   - Due Diligence = 尽职调查（尽调）
   - Social Audit = 社会责任审核（验厂）
   - Factory Audit = 验厂 / 工厂审核
   - Sedex / SMETA = Sedex / SMETA（保留英文；SMETA 不译"道德贸易审核"单独使用时保留）
   - Grade / Rating = 评级 / 等级（BSCI 评级 A–D 不改写）
   - Scope = 适用范围（不译"作用域"）
   - Effective date = 生效日期
   - Transition period = 过渡期

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 审核体系与项目：SLCP / BSCI / SMETA / SEDEX / WRAP / ICTI / RBA / Higg FEM / Cascale / Sedex / amfori
   - 反恐与安全：C-TPAT / GSV / SCAN / AEO / ISO 28000 / CT-PAT
   - 化学品与环保：ZDHC / MRSL / RSL / SVHC / REACH / OEKO-TEX / GOTS / bluesign / ECOPASSPORT / STeP
   - 质量体系：ISO 9001 / IATF 16949 / ISO 14001 / QMS / FCCA / AQL
   - 法规：CSDDD / LkSG / UFLPA / CBAM / GDPR（涉及法规时括注中文全称一次即可）
   - 版本号与清单号一字不改：MRSL 3.1 / ZDHC MRSL V2.0 / STANDARD 100 by OEKO-TEX 等
     **规则**：清单、标准的版本号绝不"翻译性扩写"（不要把 "V2.0" 译成"第二版"，不要把 "MRSL 3.1" 改写）
   - 机构与平台：SGS / Bureau Veritas（BV）/ Intertek / TÜV / UL / QIMA / Elevate / SLCP Gateway / amfori BSCI Platform / Sedex Platform / ZDHC Gateway
   - 通用技术缩写：PDF / CSV / API / URL / QR / SKU / ERP / SAAS

3. 中国机构与品牌**优先用官方中文名**（首次出现可双标，后续选一种保持一致）：
   - 海关总署 / 商务部 / 市场监管总局 / 生态环境部
   - 通标（SGS）/ 必维（Bureau Veritas）/ 天祥（Intertek）/ 莱茵（TÜV Rheinland）/ 南德（TÜV SÜD）

4. 数字、日期、条款编号 **一字不改**保留：
   - 金额、比例、条款号、生效日期保留原文的阿拉伯数字和写法；不要把 "2026 年 1 月 1 日" 改写成"今年年初"
   - 审核分数、评级字母、不符合项数量保留原文数字
   - 日期区间保留完整起止日期，不写"近期""上月"
   - URL、邮件、条款编号（如 Clause 4.1、Section 7）原样保留

5. 行业常用中文表述对照（写中文时优先用左列）：
   - 验厂准备（不说"工厂检查准备"）
   - 不符合项整改（不说"问题修复"）
   - 工资工时（不说"薪资与时间"）
   - 现场审核（不说"实地评估"）
   - 文件记录（不说"文档记录"单独用）
   - 审核报告（不说"评估报告"，SLCP 评估报告除外）
   - 供应链合规（不说"供应链顺从"）
